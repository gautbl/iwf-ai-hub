# Triage Labels

| Canonical label | Our tracker label | Meaning                                 |
| --------------- | ----------------- | --------------------------------------- |
| `needs-triage`  | `needs-triage`    | Maintainer needs to evaluate            |
| `needs-info`    | `needs-info`      | Waiting on reporter for more info       |
| `ready-for-agent` | `ready-for-agent` | Fully specified, ready for AFK agent  |
| `ready-for-human` | `ready-for-human` | Requires human implementation         |
| `wontfix`       | `wontfix`         | Will not be actioned                    |

When a skill mentions a role, use the corresponding "Our tracker label" column value.
